## 10:00 작업
**요청:** 두 가지 가독성 개선 요청 — ① 인사말(스플래시) 화면 문장이 모바일 화면에서 어절 중간에 이상하게 줄바꿈됨, 사용자가 지정한 5줄 구성대로 정갈하게 보이게 수정 ② 방금 만든 공지사항 수정 화면에서 "제목" 부분이 이상하게 보임(가독성 문제) — 확인 및 수정 요청

**작업 내용:**
- `src/components/SplashIntro.tsx`: 기존 3개 `<span>`(각 줄이 너무 길어 내부에서 재차 줄바꿈되던 문제)을 사용자가 지정한 5개 줄로 재분할하고 각 span에 `whitespace-nowrap` 적용 — "달빛은 길을 비춰주는 / 따뜻한 위로의 빛입니다. / 그 빛처럼 하미담은 / 소중한 기억과 마음을 / 정성으로 담아 전합니다." 페이드업 애니메이션 딜레이도 5단계로 재조정
- `src/routes/AdminNotices.tsx`: 공지 수정/작성 모달의 "제목" 필드를 원인 조사 — 실측 결과, 기존 단일 라인 `<input>`(Field 컴포넌트)이 값이 길 경우 넘치는 텍스트를 잘라서(clip) 보여주지 않고 숨겨버려(포커스 전에는 "...알" 뒤가 통째로 안 보임) 가독성이 떨어지는 실제 버그였음. `Field` 대신 "내용"과 동일한 스타일의 `rows={2}` textarea로 교체하여 긴 제목이 자연스럽게 2줄로 줄바꿈되어 전체가 항상 보이도록 수정, Enter 키 입력은 `preventDefault`로 막아 제목에 실제 개행문자가 들어가지 않도록 처리. 더 이상 쓰이지 않는 `Field` import 제거

**결과:** 완료.
